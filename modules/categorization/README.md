# Модуль категоризации обращений (Участник 1)

## 📌 Описание
Модуль предназначен для автоматической классификации текстовых обращений клиентов Почты России. 
Анализирует описание проблемы и метаданные (Услуга, Компонент) и относит обращение к одной из **15 наиболее частых категорий**. 

Если модель не уверена в предсказании или обращение относится к редкой/нестандартной категории, оно маркируется для **ручной обработки оператором** (Fallback).

## 🧠 Архитектура решения
Решение построено на связке семантического поиска и классического машинного обучения:
1. **Векторизация:** Используется предобученная трансформерная модель `paraphrase-multilingual-mpnet-base-v2` (768-мерные эмбеддинги). Она отлично понимает контекст, синонимы и опечатки в клиентских текстах.
2. **Классификация:** `RandomForestClassifier` с балансировкой весов классов (`class_weight='balanced'`).
3. **Калибровка:** Модель обернута в `CalibratedClassifierCV` (isotonic regression), чтобы выдаваемые вероятности были статистически достоверными. Это позволяет гибко и точно отсекать неуверенные предсказания.

## 📊 Метрики качества
По фактическому сохранённому выводу ноутбука (порог `0.25`):
* **Business Macro-F1** (только по 15 целевым классам): **0.4690**
* **Accuracy** (на автоматических ответах): **0.5066**
* **Macro-F1** (на автоматических ответах): **0.4034**
* **Fallback rate**: **39.1%** (автоматически обработано **60.9%** обращений)

> 💡 *Примечание по метрикам:* итоговые значения взяты из сохранённого вывода ноутбука, повторное обучение не выполнялось. Качество различается по классам: QR-код — F1 0.87, Препост/PrePost — 0.86, Отслеживание отправлений — 0.67, Электронные обращения — 0.59, Ошибка в приложении — 0.57. Полные дубликаты удаляются до разбиения, но близкие по смыслу записи отдельно не проверялись.

## 🛠 Установка и зависимости

1. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
2. **Важно:** При первом запуске модуль автоматически скачает веса модели эмбеддингов (~1.3 ГБ) из репозитория HuggingFace. Убедитесь, что у вас есть доступ в интернет.

## 🚀 Использование (Интеграция для команды)

Для использования в общем сервисе или API импортируйте класс `TicketCategorizer` из файла `service.py`.

```python
from service import TicketCategorizer

# Инициализация (путь к сохраненному классификатору и порог уверенности)
categorizer = TicketCategorizer(model_path="model.pkl", threshold=0.25)

# Пример 1: Уверенное предсказание
result = categorizer.predict(
    text="Не могу войти в личный кабинет, выкидывает на главную страницу",
    service="Портал pochta.ru",
    component="Личный кабинет"
)
print(result)
# Вывод: 
# {
#   'category': 'Личный кабинет', 
#   'confidence': 0.72, 
#   'is_reliable': True, 
#   'explanation': 'Уверенность модели: 0.72. Порог: 0.25.'
# }

# Пример 2: Нестандартное обращение (Fallback)
result_2 = categorizer.predict(
    text="Прошу принять в работу на основании комментария специалиста судебным участкам...",
    service="Партионный прием",
    component="Запросы из почты"
)
print(result_2['category']) 
# Вывод: 'ОПЕРАТОР' (так как is_reliable = False)
```

### Формат возвращаемого JSON (для API):
```json
{
  "category": "string (Название категории или 'ОПЕРАТОР')",
  "confidence": "float (Вероятность от 0.0 до 1.0)",
  "is_reliable": "boolean (True, если можно автоматизировать)",
  "explanation": "string (Пояснение для лога/интерфейса)"
}
```

## 📂 Структура файлов
* `service.py` — основной модуль с классом `TicketCategorizer` для инференса.
* `model.pkl` — сохранённый через `joblib.dump` откалиброванный классификатор (RandomForest); создаётся ноутбуком после обучения.
* `notebook.ipynb` — ноутбук с процессом обучения, анализа данных и расчета метрик.
* `requirements.txt` — список зависимостей Python.

## Ограничения качества и данных

Полные дубликаты удаляются по паре `(text, label_name)` до разбиения на train/test. Близкие по смыслу или слегка изменённые дубликаты отдельно не выявляются и не удаляются; поэтому метрики могут быть оптимистичными при наличии таких повторов. Трансформер `paraphrase-multilingual-mpnet-base-v2` сохраняется как обязательная часть пайплайна и автоматически скачивается при первом запуске.
