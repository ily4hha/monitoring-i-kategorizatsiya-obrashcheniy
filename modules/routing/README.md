# Участник 2 — маршрутизация и похожие обращения

Готовый комплект для передачи команде. Выполняйте команды из этой папки.
Нужен Python 3.11 или новее. При первой установке зависимостей нужен интернет.
Модель уже обучена; для демонстрации повторное обучение не требуется.

## 1. Установка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если Windows не находит `python`, используйте `py -3 -m venv .venv`.

## 2. Проверка на новом обращении

```powershell
.\.venv\Scripts\python.exe -m postcode.routing query "Не могу войти в личный кабинет, ошибка авторизации"
```

Результат JSON: линия, уверенность, объяснение, необходимость ручной проверки,
похожие обращения, их категории, линии, итоги и исходные поля.
Интерфейс общего сервиса подключает эти функции; отдельного веб-интерфейса в комплекте нет.

## 3. Подключение в коде

```python
from postcode.routing import Assistant

assistant = Assistant.load('reports/routing/assistant.joblib')
text = 'Не могу войти в личный кабинет'
recommendation = assistant.recommend_line(text)
similar = assistant.find_similar(text, exclude_id=None, limit=5)
# Для существующего обращения передайте его номер в exclude_id.
# original в каждом найденном случае содержит исходную запись для карточки.
```

Сохраняйте имя пакета `postcode`: оно используется при загрузке модели.
Файлы joblib загружайте только из доверенного источника.

## 4. Тесты и повторное обучение

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m postcode.routing train "data/raw/Обращения_1931.xlsx"
```

Повторное обучение перезаписывает модель и результаты в reports/routing.
После него для обновления отчёта:

```powershell
.\.venv\Scripts\python.exe -m postcode.finalize_routing_report
```

Содержательная разметка в этом скрипте относится только к поставляемому датасету
и текущему поиску. При изменении данных или метода её необходимо пересмотреть.

## Состав

- `postcode/` — код обучения, рекомендаций, поиска и подготовки данных.
- `reports/routing/assistant.joblib` — готовая модель и индекс только по train.
- `reports/routing/metrics.json` — показатели и матрицы ошибок.
- `reports/routing/examples.json` — удачные и ошибочные рекомендации.
- `reports/routing/records.json` — исходные поля, номера строк и принадлежность выборкам.
- `reports/routing/shared_split/` — общее разделение Excel для команды.
- `reports/routing/search_review.csv` — 30 запросов для независимой проверки поиска.
- `reports/routing/search_content_review.csv` — предварительная оценка AI десяти первых результатов.
- `docs/ROUTING_RESULTS.md` — результаты и ограничения для отчёта/защиты.
- `docs/ROUTING_AND_SEARCH.md` — подробная документация.
- `data/raw/Обращения_1931.xlsx` — исходный датасет.
- `tests/` — девять тестов.
- `SHA256SUMS.txt` — контрольные суммы комплекта.

## Основные результаты и ограничения

Accuracy test — 69.4%, baseline «первая линия» — 62.7%.
Для рекомендаций выше порога: точность 81.7%, покрытие 34.3%.
Модель выбирает линии 1–3; единственный пример линии 4 оказался в test.
Цель — фактическая линия решения, не подтверждённо оптимальная первичная маршрутизация.
Поиск иногда реагирует на шаблоны писем; группировка не исключила все близкие повторы.
Исходный результат часто является статусом без конкретного решения.
26 описаний Excel отличаются от прежнего CSV: используйте приложенное общее разбиение.
Пути к исходнику в manifest.json относятся к машине обучения и оставлены для происхождения;
локальная копия исходника находится в data/raw.
