# Результаты участника 2

Источник: Обращения_1931.xlsx, Sheet0. 1931 запись, 34 поля, 43 вида.
Excel и предыдущий CSV имеют одинаковые 1931 ID и метки, но 26 описаний различаются.
Использован Excel. Старые CSV-выборки не перезаписаны. Новое общее разбиение:
train 1281, validation 271, test 271, review 108. Команде следует использовать
reports/routing/shared_split/ с этим источником, не смешивая версии.

## Маршрутизация

TF-IDF (слова и пары слов) + логистическая регрессия, C=4, без балансировки.
Выбор балансировки и порога сделан на validation. Модель после просмотра test не менялась.

| Показатель test | Значение |
|---|---:|
| Число обращений | 271 |
| Accuracy | 69.37% |
| Правило «всегда первая линия» | 62.73% |
| Macro-F1 по 4 представленным линиям | 0.429 |
| Доля рекомендаций без флага ручной проверки | 34.32% |
| Точность этих рекомендаций | 81.72% |

Порог 0.85. На validation точность принятых рекомендаций 85.1%, на test — 81.7%:
порог не гарантирует заданного качества в новых данных. Использовать как помощь оператору.
F1 линий 1/2/3: 0.819 / 0.435 / 0.462. Единственная запись линии 4 попала в test,
в train её нет: модель не умеет выбирать эту линию. В отчёте она учтена как ошибка.
Неизвестную линию нельзя гарантированно распознать по низкой уверенности.

## Поиск

Индекс: только 1281 обучающее обращение. До пяти результатов, порог сходства 0.1,
одна запись на группу повторов. Исключение собственного ID и группы поддерживается.
На test совпадение категории хотя бы в одном из первых пяти: 66.4%, линии: 91.1%.
Это косвенные показатели, не доказательство применимости решений.

Предварительная содержательная оценка AI: первые результаты для 10 запросов
из фиксированной выборки — 4/10 тематически релевантны, 0/10 содержат конкретные
шаги решения в поле результата. Это малая выборка, не экспертная оценка.
Один релевантный результат — близкий повтор, не обнаруженный Jaccard-группировкой;
оценка может быть завышена. Общие шаблоны и подписи писем ухудшают поиск.
Полная форма для независимого оценщика: search_review.csv, 30 запросов.

## Ограничения

Поле «Кем решен» — фактическая линия решения, не подтверждённо оптимальный маршрут.
Вход — только «Описание 2», доступность всего текста при регистрации требует подтверждения.
Разбиение не временное; 108 спорных/шаблонных записей исключены из модельной оценки.
Все 43 вида сохранены для маршрутизации и поиска. Проверка утечек ограничена
лексической группировкой и не исключает все смысловые повторы.
Датасет часто хранит итоговый статус вместо инструкции решения.
